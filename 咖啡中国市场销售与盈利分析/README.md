# ☕ 咖啡中国市场分析（Coffee China Market Analysis）

## 📌 项目概述

基于 Excel 原始销售数据，在 Power BI Desktop 中完成数据清洗（Power Query）、
数据建模、DAX 度量值开发与交互式看板设计，针对中国咖啡市场
的销售表现，从**时间维度、区域维度、产品维度**三个视角，对**销量、销售额、总成本、
利润**四项核心度量进行多维度分析，为业务决策（品类结构优化、区域资源倾斜、季节性
备货、盈利结构监控）提供数据支撑。

> 📌 说明：本项目为数据分析课程设计，数据来源于咖啡中国市场销售数据集
> （含 2015–2017 年交易记录），业务场景为模拟分析。

## 🎯 分析目标

1. **核心经营状况回顾与趋势追踪**：通过时间维度（年/月）对销量与销售额进行拆解，
   展示咖啡业务的整体销售走势，识别业务高峰期与低谷期，追踪核心业绩指标达成情况。
2. **核心产品结构与爆款挖掘**：基于产品维度，对各咖啡/茶饮品类的销量及销售额贡献度
   进行归因分析，识别拉动营收的明星产品与边缘化产品，为菜单优化、新品研发及备货
   计划提供数据支撑。
3. **区域市场潜力评估**：利用区域维度（市场级别 × 市场分布：东部/西部/南部/中部）
   分析销售额的地理分布特征，定位高产出核心区域与具有增长潜力的市场，辅助区域
   营销资源倾斜与门店扩张选址决策。
4. **盈利能力监控与成本控制**：结合总成本与利润度量，建立多维度盈利分析体系，
   从单品和区域两个视角下钻，识别高毛利贡献点，同时揪出"卖得多但不赚钱"
   的异常项，提升整体业务健康度。

  - **Power Query**：数据清洗与 ETL（缺失值处理、数据类型校正、字段标准化）

    全局联动过滤

### 3. DAX 度量值与计算列
本项目在 Power BI 中编写的核心 DAX 度量值如下：

```DAX
-- 度量值：总销量
总销量 = SUM('咖啡中国市场销售数据'[销量])

-- 度量值：总销售额
总销售额 = sum('咖啡中国市场销售数据'[销售额])

-- 度量值：总利润
总利润 = SUM('咖啡中国市场销售数据'[利润])

-- 度量值：利润同比
利润同比 = var tongqi = CALCULATE([总利润],DATEADD('日期表'[日期],-1,year))
                   return DIVIDE([总利润]-tongqi,tongqi) 

-- 度量值：销售额同比all 
销售额同比all = var tongqi = CALCULATE([总销售额],DATEADD('日期表'[日期],-1,year))
                   return DIVIDE([总销售额]-tongqi,tongqi) 

-- 度量值：颜色
颜色 = if(and([总利润]>=[利润总平均all],[总销量]>=[销量总平均all]),"#00F10C",
           IF(and([总利润]>=[利润总平均all],[总销量]<[销量总平均all]),"#F1E900",
           IF(and([总利润]<[利润总平均all],[总销量]<[销量总平均all]),"#F10000",
           "#0018F1")))
```

> 💡 完整的 DAX 度量值清单见 Power BI 文件（.pbix）中的"度量值"文件夹；

#### 看板核心发现（均来自 Power BI 可视化结果）

**① 时间维度——销售季节性明显**
- 月度销售额呈波动趋势，**7 月为全年峰值（71,991）**，**11 月为全年谷值（66,106）**，
  整体围绕均值上下浮动，存在明显的夏季旺季特征。

**② 区域维度——利润集中于中部与西部市场**
- 各市场利润贡献：**中部市场 196,012（最高）> 西部市场 192,750 > 东部市场 128,463**
  （南部市场利润见看板明细）；
- 中部与西部合计贡献利润约 **388,762，占全部利润的 65.9%**，为核心产出区域。

**③ 产品维度——品类利润均衡，单品差异显著**
- 各品类利润：**花茶 51,063 > 茶 49,333 > 咖啡 49,210**，三大品类利润贡献基本均衡；
- 各产品利润：**伯爵茶 23,198 / 大吉岭茶 22,765**（头部单品），**绿茶仅 3,370**
  （尾部单品，利润贡献最低）；
- 单品"销量—利润"散点图显示：高销量产品未必高利润，存在"卖得多但不赚钱"
  的异常单品，需结合成本结构进一步诊断。

**④ 市场级别 × 品类交叉（分组柱状图）**
- 二级市场西部市场"茶"销售额约 **57 千**；一级市场中部市场"浓缩咖啡"销售额约
  **45 千**——为对应细分市场下的高贡献组合。

## 📈 核心分析结论与业务建议

### 1. 品类结构
- 花茶 / 茶 / 咖啡三大品类利润贡献均衡（均约 4.9 万–5.1 万），品类结构健康，
  无单一品类过度依赖风险。
- **建议**：保持三大品类均衡布局；对头部单品（伯爵茶 / 大吉岭茶）加大供应链
  与营销资源投入，巩固优势。

### 2. 区域分布
- **中部与西部市场为利润双核心**（合计占比 65.9%），东部市场利润贡献相对偏低
  （128,463）。
- **建议**：资源向中部/西部核心市场倾斜（加密门店/加大营销）；对东部市场做
  专项诊断（是否为消费力不足或竞争饱和），制定差异化策略。

### 3. 时间趋势
- 销售呈明显季节性，**7 月为旺季峰值、11 月为淡季谷值**。
- **建议**：针对夏季旺季（6–8 月）提前备货并设计季节性营销活动；11 月淡季
  可安排库存消化/新品试推，平衡全年产能。

### 4. 盈利与产品定位
- 头部单品（伯爵茶 / 大吉岭茶）"高销量 + 高利润"，为现金牛/明星产品；
  绿茶"低销量 + 低利润"（3,370），为瘦狗产品。
- **建议**：对"高销量但低利润"的异常单品做成本结构诊断（是否为原材料成本过高）；
  对瘦狗产品（绿茶）评估优化或淘汰，释放资源至高潜力品类。

### 5. 业务建议汇总
1. 资源向中部/西部核心利润市场倾斜，巩固优势区域。
2. 加大头部单品（伯爵茶/大吉岭茶）的供应链与营销投入。
3. 针对 7 月旺季提前备货并设计季节性营销，11 月淡季做库存消化。
4. 对"高销量低利润"单品做成本诊断，优化/淘汰瘦狗产品（如绿茶）。
