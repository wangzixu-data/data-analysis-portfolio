# 淘宝用户行为分析

> RFM 建模 · 漏斗流失 · 复购与二八分析 —— 数据分析课程项目作品集

## 一、项目概述
基于淘宝 App 平台公开用户行为数据集，从 PV/UV、付费率、复购行为、漏斗流失、用户价值（RFM）及二八分布六个维度，系统探索淘宝用户的行为模式，输出可落地的运营策略建议。

**业务价值**：识别高价值用户群、定位漏斗关键流失环节、量化复购窗口，为差异化推荐与复购促活策略提供数据支撑。

## 二、待解决的业务问题
- 日 PV / 日 UV 分别是多少，双十二等大促期间用户活跃如何变化？
- 付费（购买）率处于什么水平，活跃用户的人均消费次数如何？
- 用户复购率是多少，复购主要发生在什么时间窗口内？
- 从点击 → 加购 → 收藏 → 购买各环节的漏斗流失率如何？
- 如何用 RFM 模型对用户进行价值分层并给出差异化运营建议？
- 品类维度是否存在「二八现象」，头部品类贡献了多少购买量？

## 三、数据说明
- **来源**：天猫/阿里云天池（Tianchi）公开数据集 `tianchi_mobile_recommend_train_user.csv`
- **规模**：约 104 万行 × 6 列；时间跨度 2014-11-18 至 2014-12-18（含双十二大促）
- **字段**：user_id（用户ID·脱敏）、item_id（商品ID·脱敏）、behavior_type（1点击/2收藏/3加购/4支付）、user_geohash（地理位置哈希·脱敏，大量缺失）、item_category（品类ID）、time（行为时间，含日期+小时）
- **数据清洗**：① 缺失值：仅 user_geohash 约 71.8 万条缺失（已加密转换），不做删除；其余字段无缺失。② 一致化：将 time 拆分为 date 与 hour 两列，date/time 转日期类型、hour 保持字符串。③ 异常值：按 time 排序重置索引后 describe 检查四分位/均值/极值，未发现需剔除异常值。

## 四、技术栈
- Python 3（Pandas / NumPy）—— 数据清洗、特征工程、分组聚合
- Jupyter Notebook —— 交互式分析与结果沉淀
- Matplotlib / Seaborn —— 可视化（日 PV·UV、小时分布、消费分布、漏斗、转化率等）

## 五、分析方法与核心结论

### 5.1 日 PV/UV 与小时活跃分析
按 date / hour 分组统计 PV（行为次数）与 UV（去重用户数），并按时段统计各行为类型 PV/UV。
**结论**：双十二期间 PV 与 UV 均达峰值；数据集覆盖用户约 1 万人，双十二日活跃用户占比约 45%。凌晨 0–5 点 PV/UV 均处低位，18:00 后 PV 波动剧烈、访问活跃，是核心活跃时段；四类行为波动趋势一致，晚间各行为 PV 均最高。

### 5.2 用户消费行为分析
**付费率 ≈ 6%**：每日活跃用户中约 6% 产生购买行为，双十二期间付费用户数最多。人均消费次数（ARPPU，无金额字段以消费次数代替）在 1–2 次间波动、大促日最高；活跃用户平均消费次数约 0.075 次，大促日约 0.225 次。多数用户同一时段仅消费 1 次。

### 5.3 复购行为分析
**复购率 = 46.93%**（有 2 天及以上购买行为的用户数 / 有购买行为的用户总数）。
复购间隔主要集中在 **1–10 天**，10 天后复购显著减少；不同用户平均复购时间呈逐渐下降趋势，多数集中在 **1–5 天**间隔内。
**运营建议**：重点把握 10 天以内（尤其 1–5 天）复购窗口，对高价值用户推送复购券策略，预估可提升复购率约 15%。

### 5.4 漏斗流失分析
将行为按 点击(1) → 加购(3) → 收藏(2) → 购买(4) 构建漏斗：

| 环节 | 流失率 |
|---|---|
| 总浏览量 → 点击量 | 5.79% |
| 点击量 → 加购量 | 97.02% |
| 加购量 → 收藏量 | 28.65% |
| 收藏量 → 购买量 | 51.23% |

**结论**：点击→加购是流失最严重环节（约 97% 点击未转化为加购），收藏→购买亦超一半流失。**建议优先优化商品详情页与推荐策略，提升点击→加购转化，并对加购未购买用户做定向召回。**

### 5.5 用户价值 RFM 分析与二八分布
**RFM 分层**：基于最近购买时间（Recency）、购买频次（Frequency）、购买金额（Monetary）三维特征进行用户价值分层，识别高价值用户群。
**二八现象显著**：购买量前 20% 的高价值用户贡献约 80% 的购买量；品类按购买量降序做累计分布，可区分头部品类与长尾品类。
**运营建议**：对 Top 20% 高价值用户设计保级/专属权益策略；对流失风险用户做唤回；对头部品类持续投入、对长尾品类优化库存与推荐曝光。
