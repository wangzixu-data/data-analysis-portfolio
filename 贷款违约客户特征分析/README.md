# 银行贷款违约客户特征分析

> 基于一份含 **10008 条贷款合同 / 10009 位客户** 的银行信贷数据集，使用 **Microsoft Excel** 完成从数据检验、清洗加工、多维度交叉分析到可视化报表与报告撰写的完整数据分析流程，目标是识别贷款违约客户的高危特征，为银行风险管控提供数据支撑。

## 📌 项目概述

**业务问题**：银行风控部门希望从存量贷款客户中，找出"哪些客户特征与贷款违约高度相关"，从而辅助贷前审核与风险定价决策。

**Why this matters**：违约客户识别是消费信贷风控的核心环节。通过对存量合同的多维度交叉分析，可将"高违约率人群"从整体客群中剥离出来，为规则型风控策略（如收紧特定学历/年龄段/收入区间客户的授信）提供依据。

## 📊 数据说明

- **来源**：银行内部信贷数据（本项目为数据分析课程设计，数据为模拟信贷数据集，业务场景为模拟分析）
- **规模**：10008 条贷款合同记录、10009 位客户
- **核心表结构**（共 4 张表 + 1 张映射表）：

| 表名 | 主要字段 | 说明 |
|---|---|---|
| 客户贷款详情表 | 合同号、客户ID、贷款金额、贷款期限(月)、贷款利率(%)、合同余额、还款状态、过去两年逾期次数、贷款金额区间 | 主分析表，10008 条 |
| 客户信息表 | 客户ID、月收入、职位、年龄、性别、是否有住房贷款、是否开通信用卡、教育水平、婚姻状况、月收入区间、年龄段 | 客户维度属性，10009 条 |
| 行外信用评分表 | 客户ID、行外信用评分、评级 | 第三方信用评分，按"行外信用评分等级映射"表映射为 5 级评级 |
| 行外信用评分等级映射 | 评分范围、左侧阈值、评级 | 评分→评级映射（800-850 优秀 / 740-799 很好 / 670-739 良好 / 580-669 较差 / 300-579 极差） |
| 字段说明 | 各表字段名称、备注、数据类型 | 数据字典 |

- **目标字段**：`还款状态`（"正常" / "逾期"），整体违约率 **24.40%**（2442 / 10008）

## 🔍 分析方法与处理流程

### 1. 数据检验与处理（`一、数据检验&数据处理` 工作表）

按业务规则完成数据质量检查与衍生字段加工：

- **客户贷款详情表**
  1. 检查是否存在"一个客户有多笔合同"的情况
  2. 校验"过去两年逾期次数"与"还款状态"的一致性（正常→0 次；逾期→>0 次），定位异常记录（如合同 `WFB-0026`）
  3. 新增 `贷款金额区间` 字段，按规则分组：10 万及以下 / 10-20 万 / 20-30 万 / 30-40 万 / 40 万以上
- **客户信息表**
  1. 维度字段空值检查：若某维度空值个数超过 60% 则不作为分析维度使用（如 `婚姻状况` 空值较多，降级处理）
  2. 其余维度字段空值统一替换为 `"-"`
  3. 新增 `月收入区间` 字段：1 万及以下 / 1-2 万 / 2-3 万 / 3-4 万 / 4 万以上
  4. 新增 `年龄段` 字段：18-30 岁 / 30-40 岁 / 40-50 岁 / 50 岁及以上

### 2. 数据验证结果（`数据验证结果` 工作表）

对关键字段（如合同号/客户ID）进行重复值校验，输出每个行标签对应的记录计数，用于确认数据完整性与主键唯一性。

### 3. 分析需求拆解与思路梳理（`二、分析需求` / `思路梳理` 工作表）

采用 **What / Why / Who / When / Where / How much / How to do** 七问法拆解需求，明确：

- **分析维度**：贷款金额区间、贷款期限(月)、还款状态、月收入区间、职位、年龄段、性别、是否有住房贷款、是否开通信用卡、教育水平、评级
- **分析指标**：违约人数、违约率（= 逾期人数 / 该维度项总人数）
- **分析表**：上述四张表
- **分析方法**：数据透视分析（Pivot Table）—— 统计各维度项下的违约人数与违约率
- **产出链路**：业务理解 → 数据获取(Excel) → 数据处理(6 步加工) → 数据分析(透视) → 报表绘制 → 报告撰写(Word)

### 4. 多维度交叉分析（`准备区` + `报表区` 工作表）

使用 Excel 数据透视表，对以下 **9 个维度** 逐一统计"逾期 / 正常 / 总计"人数及违约率：

| 维度 | 主要发现（违约率） |
|---|---|
| 性别 | 男 **27.02%** / 女 12.57%（整体基线 24.40%） |
| 年龄段 | 40-50 岁 **47.37%**；50 岁及以上仅 3.79% |
| 月收入区间 | 1-2 万 **26.28%**（占比最大区间）；随收入升高违约率下降（4 万以上 17.15%） |
| 教育水平 | 大专 **86.03%** / 中专 85.74% / 其他 49.03%；本科 5.39% / 硕士 7.24% / 博士 4.45% |
| 评级 | 良好 24.93% / 优秀 24.00% / 极差 20.59% / 较差 14.66% |
| 是否开通信用卡 | 未开通 26.91% / 开通 8.93% |
| 是否有住房贷款 | 有 24.95% / 无 20.09% |
| 贷款金额区间 | 10 万及以下 **29.35%**；10 万以上区间违约率显著更低（10-20 万 4.97% / 20-30 万 5.64% / 30-40 万 3.08%） |
| 贷款期限(月) | 12 个月占比最大（5258 条，52.5%），违约率 26.97%；8 个月 43.24%、24 个月 41.07%、11 个月 47.83% 等小样本区间违约率偏高 |

### 5. 可视化与报告（`报表区` 工作表 + Word 报告）

- 在 `报表区` 工作表中基于透视结果绘制 **9 张 Excel 图表**，覆盖上述核心维度的违约率对比
- 结合图表与数据结论撰写 Word 分析报告，输出"违约客户特征画像 + 风控建议"

## 📈 核心结论

1. **教育水平是最强区分维度之一**：大专（86.03%）、中专（85.74%）客户违约率远高于本科（5.39%）、硕士（7.24%）、博士（4.45%），相差约 12–20 倍，是贷前审核应重点关注的硬指标。
2. **40-50 岁年龄段为违约高发区间**：违约率 47.37%，约为整体基线（24.40%）的 1.9 倍；50 岁以上客户违约率仅 3.79%，风险最低。
3. **小额贷款（≤10 万）违约率反而最高**：10 万及以下区间违约率 29.35%，显著高于 10 万以上各区间（3%–6%），提示"小额高频"客群存在更高违约倾向。
4. **男性客户违约率约为女性的 2.15 倍**（27.02% vs 12.57%），结合职位分布（业务拓展人员、软件工程师为两大主力客群）可进一步细分。
5. **未开通信用卡客户违约率高于已开通客户**（26.91% vs 8.93%），与"信用行为记录缺失"的风控直觉一致。
